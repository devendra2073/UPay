Direct-to-Bank UPI Gateway

UPay is a zero-commission, non-custodial UPI checkout bridge. Customer payments flow directly into your verified Paytm Business VPA via dynamic UPI intents without intermediary escrow holds.

0% Gateway Fees

Completely free of third-party processing deductions. All settled funds stay 100% yours.

Zero Custody Escrow

Settlement happens directly between the customer’s UPI app and your merchant bank account.

Instant Webhook Verification

Real-time POST callbacks secured with cryptographically verified HMAC-SHA256 signatures.

Merchant Onboarding

Follow these steps to generate your merchant authentication credentials:

  1. Register Merchant Account: Access your portal at u-pay-seven.vercel.app/user/login and complete Google or email authentication.
  2. Link Paytm Business: Add your verified Paytm Business Merchant VPA (UPI ID) and Merchant Identifier (MID).
  3. Retrieve Credentials: Under the API section, copy your production Secret Key and MID.

Webhook Configuration

Set up delivery endpoints in your dashboard under Webhook Handlers to process instant transaction confirmations.

Field Destination & Behavior
Success Callback URL Your backend server listener. UPay triggers a secure HTTP POST with payment details immediately upon successful settlement.
User Redirect URL Browser redirection target where the buyer is returned after completing payment. If left blank, UPay shows its default success page.
⚠️
Server Requirement: Your callback URL must resolve over HTTPS and acknowledge payload delivery by returning an immediate 200 OK within 3.0 seconds.

Create Order API

Generate a dynamic payment transaction session and retrieve checkout URLs.

POST https://www.u-pay-seven.vercel.app/api/create-order

Request Body

Parameter Type Status Description
api String Required Your Merchant Secret Key from the dashboard.
MID String Required Your Paytm Merchant Identifier.
amount Number / String Required Order amount in INR (e.g. 2399.00).
customerEmail String Required Buyer email for payment verification and receipts.
customerName String Optional Customer full name.
customerMobile String Optional 10-digit customer mobile number.

Response Payload

200 OK — application/json 
{
  "status": true,
  "order": "ORDER_67A419B8E3D",
  "message": "Order Created",
  "link": "https://www.u-pay-seven.vercel.app/pay/ORDER_67A419B8E3D",
  "timestamp": 1740000000000
}

Redirect the buyer to the generated link to present the dynamic QR code and auto-detect installed UPI apps (GPay, PhonePe, Paytm, BHIM).

HMAC Signature Verification

When a transaction settles, UPay issues an asynchronous webhook to your configured listener:

Webhook Callback Body 
{
  "ORDERID": "ORDER_67A419B8E3D",
  "amount": 2399.00,
  "UTR": "738273824123",
  "status": "SUCCESS",
  "signature": "c044d03df6da5cb676e279bc8d6268846c4f74d08ec4f5d609204bf235e165fa"
}
💡
Verification Format: Concatenate the string ORDERID|amount|UTR|status using pipe separators, then hash it using HMAC-SHA256 with your Secret Key.

Node.js / Express Implementation

server.js 
const express = require('express');
const crypto = require('crypto');
const app = express();

app.use(express.json());

app.post('/api/webhook', (req, res) => {
  const { ORDERID, amount, UTR, status, signature } = req.body;
  const secretKey = process.env.UPAY_SECRET_KEY;

  // 1. Build canonical pipe-separated string
  const payload = `${ORDERID}|${amount}|${UTR}|${status}`;

  // 2. Compute expected HMAC-SHA256 hash
  const expectedSignature = crypto
    .createHmac('sha256', secretKey)
    .update(payload)
    .digest('hex');

  // 3. Timing-safe constant-time comparison
  const isValid = crypto.timingSafeEqual(
    Buffer.from(signature, 'hex'),
    Buffer.from(expectedSignature, 'hex')
  );

  if (!isValid) {
    return res.status(400).send("Signature mismatch: unauthorized request");
  }

  // 4. Fulfill order in your database
  console.log(`Payment confirmed for Order ${ORDERID} via UTR ${UTR}`);

  res.status(200).json({ received: true });
});
