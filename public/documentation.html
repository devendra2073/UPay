Direct UPI Payment Gateway

UPay is a zero-commission, direct-to-account UPI payment bridge. Payments settle straight to your Paytm Business merchant VPA with zero escrow custody risk.

0% Gateway Fees

Zero processing fees. 100% of received payments remain directly in your merchant bank account.

Zero Custody

Instant UPI settlement without intermediate third-party account holding.

HMAC-SHA256 Webhooks

Tamper-proof signature calculated directly across the raw stringified payload object.

Merchant Onboarding

To begin processing payments, grab your credentials from the merchant console:

  1. Register Merchant Account: Sign in at u-pay-seven.vercel.app/user/login .
  2. Link Paytm Business: Configure your verified Paytm Business UPI ID and Merchant Identifier (MID).
  3. Copy API Secret: Under the API tab, copy your secret key (passed as api in order creation).

Webhook Configuration

Configure your webhook endpoints in the dashboard under Webhook Handlers:

Configuration Description
Success Callback URL Your backend server webhook endpoint. Receives POST callbacks containing the transaction payload and signature.
User Redirect URL Browser redirect URL after user completes payment. (Optional: falls back to default receipt screen if empty).
⚠️
Server Requirement: Your callback URL must use HTTPS and respond with 200 OK within 3 seconds to acknowledge receipt.

Create Order API

Create a dynamic transaction token and fetch the payment checkout link.

POST https://www.u-pay-seven.vercel.app/api/create-order

Request Body

Parameter Type Status Description
api String Required Your secret API key.
MID String Required Your Paytm Merchant Identifier.
amount Number / String Required Transaction amount in INR.
customerEmail String Required Customer email address.
customerName String Optional Customer display name.
customerMobile String Optional 10-digit customer phone number.

HMAC Signature Verification

When an order completes, UPay dispatches a POST callback containing payment confirmation details:

Incoming Webhook Payload 
{
  "ORDERID": "ORDER_67A419B8E3D",
  "amount": 2399,
  "UTR": "738273824123",
  "status": "SUCCESS",
  "signature": "3fd5b3539bc7aef66f4db9b977bc698bb2c222ce045b13697e84bf9cb83bf2ee"
}
💡
Signature Calculation Rule: The signature is calculated by taking JSON.stringify() of the payment details (keys: ORDERID, amount, UTR, status) and hashing it using HMAC-SHA256 with your Secret Key.

Node.js Backend Verification

express-webhook.js 
const express = require('express');
const crypto = require('crypto');
const app = express();

app.use(express.json());

app.post('/api/webhook', (req, res) => {
  const { ORDERID, amount, UTR, status, signature } = req.body;
  const secretKey = process.env.UPAY_SECRET_KEY; // Your API secret key

  // Re-create the exact stringified object
  const payment_info = JSON.stringify({
    ORDERID,
    amount,
    UTR,
    status
  });

  // Calculate HMAC-SHA256 signature
  const expectedSignature = crypto
    .createHmac("sha256", secretKey)
    .update(payment_info)
    .digest("hex");

  // Constant-time comparison
  const isValid = crypto.timingSafeEqual(
    Buffer.from(signature, 'hex'),
    Buffer.from(expectedSignature, 'hex')
  );

  if (!isValid) {
    return res.status(400).send("Signature verification failed!");
  }

  // Fulfill order in your database
  console.log(`Payment confirmed for Order ${ORDERID} with UTR ${UTR}`);

  res.status(200).json({ received: true });
});
