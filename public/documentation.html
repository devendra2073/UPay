Webhook Notification & HMAC Signature

As soon as the payment hits your merchant UPI rail, the UPay engine triggers a POST request to your Success Callback URL.

Webhook JSON Body:

{
  "ORDERID": "Ord1212212",
  "amount": 2399.00,
  "UTR": "738273824",
  "status": "SUCCESS",
  "signature": "a3b5c7...64-char-hex-hmac-sha256-string..."
}

Tamper-Proof Verification Logic

To guarantee that the request genuinely came from UPay and was not spoofed by an attacker, UPay signs the stringified transaction data: {"ORDERID":"...","amount":...,"UTR":"...","status":"SUCCESS"} using your API Secret Key as the HMAC-SHA256 secret.

Node.js / Express Webhook Handler 
const express = require('express');
const crypto = require('crypto');
const app = express();

app.use(express.json());

app.post('/api/payment/callback', (req, res) => {
  const { ORDERID, amount, UTR, status, signature } = req.body;
  const SECRET_KEY = process.env.UPAY_SECRET_KEY;

  // 1. Construct the payload structure to verify
  const dataToSign = JSON.stringify({
    ORDERID,
    amount,
    UTR,
    status
  });

  // 2. Generate expected HMAC SHA256 hex string
  const expectedSignature = crypto
    .createHmac('sha256', SECRET_KEY)
    .update(dataToSign)
    .digest('hex');

  // 3. Constant-time comparison to prevent timing attacks
  const isValid = crypto.timingSafeEqual(
    Buffer.from(signature || '', 'hex'),
    Buffer.from(expectedSignature, 'hex')
  );

  if (!isValid) {
    console.error("Tampered webhook signature detected!");
    return res.status(401).json({ message: "Invalid Signature" });
  }

  // 4. Signature verified! Fulfill customer order in database
  console.log(`Payment confirmed for Order ${ORDERID}, Bank UTR: ${UTR}`);
  // db.orders.update({ id: ORDERID }, { status: 'PAID', utr: UTR });

  // 5. Must return 200 OK within 3 seconds
  return res.status(200).json({ status: "ACK" });
});
Python / Flask / FastAPI Verification 
import hmac
import hashlib
import json
import os
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/api/payment/callback', methods=['POST'])
def upay_webhook():
    payload = request.json
    received_signature = payload.get('signature', '')
    secret_key = os.getenv("UPAY_SECRET_KEY")

    # Reconstruct data dictionary identical to UPay
    data = {
        "ORDERID": payload.get("ORDERID"),
        "amount": payload.get("amount"),
        "UTR": payload.get("UTR"),
        "status": payload.get("status")
    }

    raw_string = json.dumps(data, separators=(',', ':'))
    computed_signature = hmac.new(
        secret_key.encode('utf-8'),
        raw_string.encode('utf-8'),
        hashlib.sha256
    ).hexdigest()

    if not hmac.compare_digest(received_signature, computed_signature):
        return jsonify({"message": "Invalid HMAC signature"}), 400

    # Process order fulfillment logic here
    print(f"Verified payment for Order {data['ORDERID']} with UTR {data['UTR']}")
    return jsonify({"status": "SUCCESS"}), 200
