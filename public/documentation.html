UPay UPI Payment Gateway

UPay is a zero-fee, developer-friendly UPI checkout bridge. Customer payments go straight into your verified Paytm Business VPA without third-party intermediary holding funds.

0% Commission

Completely free of gateway fees. All settled funds stay 100% yours.

Zero Custody Risk

Money settles directly from the customer’s UPI app into your Paytm Business account.

Instant Webhooks

Real-time POST callbacks secured with tamper-proof HMAC-SHA256 signatures.

Merchant Onboarding

Follow these steps to activate your merchant account and grab your credentials:

  1. Create Account: Head to https://www.u-pay-seven.vercel.app/user/login and sign in using your Email or Google OAuth.
  2. Connect Paytm Business: Provide your Paytm Business Merchant UPI ID and Merchant Identifier (MID).
  3. Obtain API Credentials: Switch to the API tab in your dashboard and copy your:
    • Secret Key (API Key)
    • Merchant Identifier (MID)

Webhook Configuration

In your dashboard under Webhook Handlers, configure the URLs where our systems send real-time transaction updates and redirect buyers.

Field Description
Success Callback URL Your backend webhook listener. UPay fires an HTTP POST request to this URL as soon as the customer finishes payment.
User Redirect URL Where the user's browser is forwarded after completing payment. If left blank, users go to our default success screen.
⚠️
Server Requirement: Your callback endpoint must support HTTPS and return an immediate 200 OK response within 3 seconds to acknowledge delivery.

Create Order API

Initialize a dynamic UPI transaction and fetch a payment page link.

POST https://www.u-pay-seven.vercel.app/api/create-order

Request Body

Parameter Type Status Description
api String Required Your API Secret Key from the API panel.
MID String Required Your Merchant Identifier (MID).
amount Number/String Required Transaction amount in INR (e.g. 2399.00).
customerName String Optional Customer's display name.
customerEmail String Required Email address for payment receipt.
customerMobile String Optional Customer's 10-digit mobile number.

Example Response

JSON 200 OK 
{
  "status": true,
  "order": "ORDER_67A419B8E3D",
  "message": "Order Created",
  "link": "https://www.u-pay-seven.vercel.app/pay/ORDER_67A419B8E3D",
  "timestamp": 1740000000000
}

Redirect your user to the returned link to show the dynamic QR code and UPI application buttons (GPay, PhonePe, Paytm, BHIM).

HMAC Verification & Webhook Handling

When an order completes, UPay issues a POST request to your Success Callback URL:

Incoming Webhook Payload 
{
  "ORDERID": "ORDER_67A419B8E3D",
  "amount": 2399.00,
  "UTR": "738273824123",
  "status": "SUCCESS",
  "signature": "c044d03df6da5cb676e279bc8d6268846c4f74d08ec4f5d609204bf235e165fa"
}
💡
Signature String Construction: To verify integrity, concatenate ORDERID|amount|UTR|status and hash it using HMAC-SHA256 with your Secret Key.

Node.js Verification Snippet

express-webhook.js 
const crypto = require('crypto');

app.post('/api/webhook', (req, res) => {
  const { ORDERID, amount, UTR, status, signature } = req.body;
  const secretKey = process.env.UPAY_SECRET_KEY;

  // Construct canonical payload string
  const payload = `${ORDERID}|${amount}|${UTR}|${status}`;

  // Compute expected HMAC SHA256 hex string
  const expectedSignature = crypto
    .createHmac('sha256', secretKey)
    .update(payload)
    .digest('hex');

  // Secure constant-time comparison
  const isValid = crypto.timingSafeEqual(
    Buffer.from(signature, 'hex'),
    Buffer.from(expectedSignature, 'hex')
  );

  if (!isValid) {
    return res.status(400).send("Signature Mismatch — Tampering Detected");
  }

  // Fulfill user's order in your database
  console.log(`Payment confirmed for Order ${ORDERID} via UTR ${UTR}`);

  res.status(200).json({ received: true });
});
