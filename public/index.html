POST /api/payment/create
Live Production Endpoint

Generates a dynamic payment order with a valid UPI payload and instant checkout URL.

Parameter Type Requirement Description
amount Number Required Amount in INR (e.g. 499.00)
orderId String Required Unique identifier from your store database
customerName String Required Payer reference name displayed on app screens

Express Receiver Implementation

const express = require('express');
const app = express();

app.post('/webhook', express.json(), (req, res) => {
  const { orderId, status, utr } = req.body;

  if (status === 'SUCCESS') {
    fulfillOrder(orderId, utr);
  }

  res.status(200).send('OK');
});
