Create Order Endpoint

Initiate a payment order by providing your secret key (`api`) and merchant identifier (`MID`).

POST https://www.u-pay-seven.vercel.app/api/create-order
Content-Type: application/json

Creates a payment session and returns a dynamic payment link (`/pay/:orderId`) containing QR codes and app intent triggers.

Field Type Status Description
api String Required Your secret API Key generated from dashboard
MID String Required Your Paytm Merchant Identifier
amount Number/String Required Order amount in INR (e.g. 2399 or "2399.00")
customerEmail String Required Customer email for notification and confirmation
customerName String Optional Payer name for your transaction records
customerMobile String Optional 10-digit mobile phone number

Tamper-Proof Verification

Webhook Security & HMAC

When a payment completes, UPay issues an HTTP POST callback to your Success Callback URL. Verify the signature by computing HMAC-SHA256 across the exact stringified payload object.

Incoming Webhook Payload

POST (Callback URL)
{
  "ORDERID": "ORDER_67A419B8E3D",
  "amount": 2399,
  "UTR": "738273824123",
  "status": "SUCCESS",
  "signature": "3fd5b3539bc7aef66f4db9b977bc..."
}
Hashing Specification: The signature is calculated by taking JSON.stringify({ ORDERID, amount, UTR, status }) and hashing it using HMAC-SHA256 with your merchant Secret Key (api).

Express Backend Handler

Node.js + crypto
const express = require('express');
const crypto = require('crypto');
const app = express();

app.use(express.json());

app.post('/api/webhook', (req, res) => {
  const { ORDERID, amount, UTR, status, signature } = req.body;
  const secretKey = process.env.UPAY_SECRET_KEY;

  // 1. Stringify payload matching gateway
  const payment_info = JSON.stringify({
    ORDERID,
    amount,
    UTR,
    status
  });

  // 2. Compute expected HMAC
  const expectedSignature = crypto
    .createHmac("sha256", secretKey)
    .update(payment_info)
    .digest("hex");

  // 3. Constant-time comparison
  const isValid = crypto.timingSafeEqual(
    Buffer.from(signature, 'hex'),
    Buffer.from(expectedSignature, 'hex')
  );

  if (!isValid) {
    return res.status(400).send("Tampering detected");
  }

  // 4. Fulfill order
  fulfillOrderInDatabase(ORDERID, UTR);
  res.status(200).json({ received: true });
});
